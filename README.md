# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint/Oxlint rules.

## Available Scripts

- `npm run dev` — Starts the development server
- `npm run build` — Builds the app for production (Vercel-ready)
- `npm run preview` — Previews the production build locally

## Deployment

Configured for seamless deployment on Vercel with single-page app rewrites via `vercel.json`.
